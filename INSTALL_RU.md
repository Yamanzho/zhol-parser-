# Установка Жол на новый Mac

Пошаговая инструкция для чистой установки: новый компьютер, пустая база. Каждую команду можно скопировать в Терминал целиком.

Жол работает только на macOS. Windows и Linux не поддерживаются.

English version: [INSTALL.md](INSTALL.md).

## Что получится

- База PostgreSQL в Docker на этом Mac. Наружу она не открыта.
- Панель в браузере по адресу `http://127.0.0.1:15173`.
- Сборщик Chrome, который сам запускается при входе в macOS.
- Сбор из 2ГИС и Google Maps по 147 категориям и выгрузка в Excel.

Пароли, токены и собранные компании хранятся только на этом компьютере. В GitHub они не попадают.

## 1. Установите программы

Откройте Терминал: Finder, затем «Программы», «Утилиты», «Терминал».

**Homebrew**, менеджер программ для Mac. Если команда `brew --version` уже что-то показывает, этот шаг пропустите.

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

В конце установщик Homebrew покажет две команды `echo ... >> ~/.zprofile` и `eval ...`. Выполните их, затем закройте и снова откройте Терминал.

**Git, Python 3.12, Docker Desktop и Google Chrome:**

```bash
brew install git python@3.12
brew install --cask docker-desktop google-chrome
```

Проверка:

```bash
git --version
python3.12 --version
```

Вторая команда должна показать `Python 3.12` или новее. Обычная команда `python3` на macOS бывает версии 3.9, поэтому дальше везде используется `python3.12`.

**Запустите Docker Desktop:** откройте его из «Программ», примите условия и дождитесь надписи «Engine running». Проверка:

```bash
docker info
docker compose version
```

Обе команды должны отработать без ошибки.

## 2. Скачайте Жол из GitHub

```bash
cd ~
git clone https://github.com/Yamanzho/zhol-parser-.git zhol
cd ~/zhol
git checkout v1.0.1
```

Если репозиторий закрытый, Git попросит войти. Проще всего один раз выполнить `brew install gh && gh auth login` и повторить `git clone`.

Дальше все команды выполняются из папки `~/zhol`.

## 3. Установите зависимости Python

Сборщик Chrome и команды для Google Maps работают из локального окружения `.venv` в папке проекта. Установщик его не создает, поэтому сделайте это до установки:

```bash
cd ~/zhol
python3.12 -m venv .venv
.venv/bin/python -m pip install --upgrade pip
.venv/bin/python -m pip install -e ".[browser,collector]"
.venv/bin/python -m playwright install chromium
```

Ставьте пакеты именно через `.venv/bin/python -m pip`, а не через `pip`: так они точно попадут в это окружение.

Проверка:

```bash
.venv/bin/python -c "import zhol, sqlalchemy, selenium, playwright; print('ok')"
```

## 4. Установите Жол: .env и пустая база

В Finder откройте папку `zhol` и дважды щелкните `Установить Zhol.command`. Можно и из Терминала:

```bash
cd ~/zhol
/bin/bash "Установить Zhol.command"
```

Если macOS напишет, что файл от неизвестного разработчика: щелкните его правой кнопкой, выберите «Открыть» и подтвердите.

Что делает установщик:

1. Проверяет Python 3.12, Docker Desktop и Google Chrome.
2. Создает `.env` из шаблона `.env.example` и сам записывает случайные пароли базы, ключи и локальный вход. Придумывать и вписывать пароли не нужно. Уже существующий `.env` не переписывается.
3. Создает пустую базу PostgreSQL (пользователь `zhol`, база `zhol`), если ее еще нет. Существующая база не удаляется.
4. Ставит сборщик Chrome для вашего пользователя macOS: службу `kz.duna.zhol.collector`.

Не публикуйте `.env` и не отправляйте его другим людям: в нем пароли.

## 5. Разрешения на сбор

Сбор из каждой площадки открывается отдельно, только при наличии письменного разрешения. Пустое значение оставляет площадку закрытой, и это нормально.

Откройте `.env` в TextEdit:

```bash
open -e ~/zhol/.env
```

Найдите строки и впишите текст вашего разрешения, только если оно у вас есть:

```text
ZHOL_2GIS_BROWSER_GRANT=
ZHOL_GOOGLE_BROWSER_GRANT=
```

Допустимы только два значения: `written-browser-retention-local` или `written-browser-retention-commercial`. Разрешение одной площадки не открывает другую. Сохраните файл.

## 6. Запустите Жол

Дважды щелкните `Запустить Zhol.command` или выполните:

```bash
cd ~/zhol
/bin/bash "Запустить Zhol.command"
```

Первый запуск собирает образы Docker, это занимает 5-15 минут. Потом скрипт:

1. запускает базу и ждет ее готовности;
2. создает таблицы в новой пустой базе;
3. запускает API, панель, очереди задач и резервное копирование;
4. открывает панель в браузере.

В конце появится строка `Жол запущен: http://127.0.0.1:15173/`.

Затем перезапустите сборщик Chrome, чтобы он прочитал разрешения из шага 5:

```bash
cd ~/zhol
scripts/zhol-collector-macos.sh restart
scripts/zhol-collector-macos.sh status
```

В выводе `status` должно быть `launchd: loaded` и номер процесса `pid`.

## 7. Откройте панель и войдите

Откройте в браузере:

```text
http://127.0.0.1:15173
```

Нажмите «Открыть панель». Токен вводить не нужно: на этом компьютере вход локальный. Панель открывается только по адресу `127.0.0.1` или `localhost`. С другого компьютера в сети она недоступна.

Вверху четыре раздела: «Сбор», «Компании», «Выгрузка», «Дополнительно».

## 8. Сбор из 2ГИС и Google Maps по 147 категориям

В разделе «Сбор»:

1. «Площадка»: 2ГИС или Google Maps.
2. «Город»: например, Алматы.
3. Отметьте «Все категории». Поле запроса станет неактивным, а Жол возьмет все 147 категорий из каталога `config/categories.yaml`.
4. «Компаний на категорию»: от 1 до 3. Всего за один сбор берется не больше 500 компаний, поэтому 147 категорий × 3 = 441 это максимум.
5. Нажмите «Начать сбор». Откроется «История сбора» с ходом выполнения.

Чтобы собрать и 2ГИС, и Google Maps, запустите сбор два раза, по одному на площадку. Либо откройте «Дополнительно», затем «История сбора»: там полная форма, в которой можно отметить обе площадки сразу, выбрать несколько городов и задать «Лимит на сочетание» (сколько компаний на одну категорию).

Для одной категории или своего запроса не отмечайте «Все категории», а впишите текст в «Категория или запрос», например `кофейня`.

Во время сбора открывается отдельное окно Chrome. Не закрывайте его. Если площадка показывает проверку «я не робот», ее проходит человек в этом окне. Программа такие проверки не решает и не обходит.

Сбор можно поставить на паузу, продолжить или остановить. Уже собранные компании остаются в базе.

Совет для первой проверки: Алматы, «Все категории», 1 компания на категорию. Это 147 карточек на площадку.

## 9. Выгрузка в Excel

- **Раздел «Выгрузка»:** выберите все задания или одно, формат Excel и скачайте файл.
- **Один сбор:** «Дополнительно», «История сбора», откройте сбор и нажмите «Скачать Excel». В файле только компании этого сбора.
- **Общий файл 2ГИС и Google:** в «Истории сбора» есть выгрузка `2gis-google.xlsx` с отдельными листами «2ГИС» и «Google Maps».

Файлы сохраняются в папку «Загрузки» вашего браузера.

## 10. Остановка и повторный запуск

Остановить, не удаляя данные:

```bash
cd ~/zhol
/bin/bash "Остановить Zhol.command"
```

Запустить снова: Docker Desktop должен быть открыт, затем

```bash
cd ~/zhol
/bin/bash "Запустить Zhol.command"
```

Повторный запуск без изменений программы пропускает сборку образов и занимает около минуты.

Сборщик Chrome:

```bash
scripts/zhol-collector-macos.sh status
scripts/zhol-collector-macos.sh stop
scripts/zhol-collector-macos.sh start
```

После обновления программы (`git pull`) сначала дважды щелкните `Обновить базу Zhol.command`: он делает копию базы и обновляет ее схему. Затем снова `Запустить Zhol.command`.

## 11. Частые ошибки

| Сообщение или признак | Что сделать |
|---|---|
| «Нужен Python 3.12 или новее» | `brew install python@3.12`, затем снова `Установить Zhol.command`. |
| «Docker не установлен» или «Docker Desktop не запущен» | Откройте Docker Desktop, дождитесь «Engine running», повторите. |
| «Google Chrome не найден» | `brew install --cask google-chrome`. Chrome должен лежать в `/Applications`. |
| «Файла .env нет» | Сначала запустите `Установить Zhol.command`. |
| Панель не открывается | Смотрите журнал `~/Library/Logs/Zhol/startup.log`. Если порт занят, остановите Жол, поменяйте `API_PORT` или `WEB_PORT` в `.env` и запустите снова. |
| «Схема базы не совпадает с программой» | Дважды щелкните `Обновить базу Zhol.command`, затем `Запустить Zhol.command`. |
| Площадка в форме «недоступна» | Для нее не задано разрешение в `.env` (шаг 5). Задайте, запустите Жол и `scripts/zhol-collector-macos.sh restart`. |
| Сбор «Ждет проверку в браузере» | В окне Chrome площадка просит пройти проверку. Пройдите ее вручную и нажмите «Продолжить». |
| `ModuleNotFoundError` или «playwright is not installed» в журнале сборщика | Повторите шаг 3. |
| `Executable doesn't exist ... Chromium` | Выполните `.venv/bin/python -m playwright install chromium`. Если задана переменная `PLAYWRIGHT_BROWSERS_PATH`, уберите ее: `unset PLAYWRIGHT_BROWSERS_PATH`. |
| Сбор Яндекса прерывается | Ожидаемо: страница ограничения доступа останавливает задание. Обход не предусмотрен. |

Журналы:

- запуск: `~/Library/Logs/Zhol/startup.log`
- сборщик Chrome: `~/Library/Logs/Zhol/collector.log` и `collector.err.log`
- ошибки сборщика кратко: `scripts/zhol-collector-macos.sh errors`

Данные хранятся в томе Docker проекта. Остановка, перезапуск и повторная установка их не удаляют. Не выполняйте `docker compose down -v`: эта команда удаляет базу.

Подробнее: [docs/TROUBLESHOOTING_RU.md](docs/TROUBLESHOOTING_RU.md) и [docs/USER_GUIDE_RU.md](docs/USER_GUIDE_RU.md).
