# Жол

Жол собирает карточки компаний в 2ГИС, Яндекс Картах и Google Maps и хранит результат в локальной базе PostgreSQL. Панель открывается только на этом компьютере, по адресу `http://127.0.0.1`.

Короткий запуск и учебный режим без базы: [docs/QUICKSTART_RU.md](docs/QUICKSTART_RU.md). Дважды щелкните `Запустить демо Zhol.command`, если нужно посмотреть сбор, поиск и выгрузку без Docker и без карт.

Программа рассчитана на macOS. База, пароли и разрешения на сбор остаются на компьютере пользователя и не входят в репозиторий.

## Что нужно заранее

- macOS с графическим сеансом
- Docker Desktop
- Python 3.12 или новее
- Google Chrome

Пароли PostgreSQL и вход в панель создаются при установке. Их не нужно придумывать и не нужно копировать с другого компьютера.

## Установка и запуск

1. Клонируйте репозиторий и откройте его папку.
2. Дважды щелкните `Установить Zhol.command`.
3. Дважды щелкните `Запустить Zhol.command`. Скрипт соберет образы, применит миграции и откроет панель.
4. Чтобы остановить службы, не удаляя базу, щелкните `Остановить Zhol.command`.

Подробности: [docs/INSTALL_MAC_RU.md](docs/INSTALL_MAC_RU.md). Как собрать компании: [docs/USER_GUIDE_RU.md](docs/USER_GUIDE_RU.md).

## Сбор

В панели выбирают город, категорию или свой поисковый запрос и источники. Справочник содержит 29 населенных пунктов Казахстана. 2ГИС доступен для 22 городов с известным адресом страницы. Яндекс Карты в этом справочнике открываются только для Алматы. Google Maps доступен для всех 29 пунктов. Город вне справочника не подменяется Алматы.

Категории берутся из `config/categories.yaml`: салон красоты, парикмахерская, фитнес-клуб, тренажерный зал, ресторан, стоматология, медицинский центр. Слова «салон», «студия» и «центр» сами по себе категорией не становятся.

Сбор можно поставить на паузу, продолжить или остановить. Уже записанные компании при остановке остаются в базе.

Живой сбор Яндекс Карт не гарантируется. Страница с текстом ограничения доступа останавливает задание. Ответ HTTP 429 сервер может отдать и без кода в журнале сборщика. Обход таких ограничений в программу не входит.

## Где лежат данные

- PostgreSQL в томе Docker этого проекта. Том не публикуется в интернет.
- Excel выгружает листы «2ГИС» и «Google Maps». Строки Яндекса остаются в базе и в этот файл не попадают.
- Файлы `.env`, выгрузки, журналы и профили Chrome в Git не коммитятся.

Разрешение на сбор в браузере задается отдельно для каждой площадки в `.env`. Пустое значение оставляет источник закрытым. Значения из чужой установки сюда не копируются.

## Проверка

```bash
python3 -m pytest
cd web && npm ci && npm run build
```

Тесты не открывают живые сайты карт. Эталонная таблица салонов и база контактов в публичный репозиторий не входят: тесты, которым они нужны, пропускаются, если файлов нет.
