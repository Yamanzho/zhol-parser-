# Чек-лист: просьба клиента на подписке → правки

Материалы: сообщение клиента, данные клиента, свежие снимки, правки агента, счётчик лимита.

Пункты `[главный]`: без их проверки точка не имеет смысла (`03`, раздел 5).

1. [главный] Правка не следует из сообщения клиента или его файлов: critical.
2. Неясная просьба превращена в правку вместо вопроса клиенту: critical.
3. Поле правки не то, о чём просил клиент (например, просил цены, а правка в описании): critical.
4. Просьба вне обслуживания не помечена `out_of_scope`: major.
(Пометки «название, адрес, телефон, рубрика» и «входит в лимит» ставит код, их не проверять.)
