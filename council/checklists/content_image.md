# Чек-лист: изображение (Өнер), проверка картинки

Материалы: готовая картинка или кадры видео, список реальных файлов клиента, использованных в работе, макет.

Пункты `[главный]`: без их проверки точка не имеет смысла (`03`, раздел 5).

1. [главный] На картинке есть люди, лица, руки, интерьер или работы мастеров, которых нет среди реальных файлов клиента (то есть сгенерированные): critical.
2. Текст обрезан, нечитаем на фоне, перекрыт: major.
3. Логотип искажён или чужой: major.
4. Картинка не соответствует задаче (обложка вместо баннера акции и т. п.): major.
