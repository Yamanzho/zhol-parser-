# Чек-лист: отчёт приёмки этапа (консилиум разработки)

Материалы: файл этапа `docs/plan/stages/Sx.md`, отчёт `docs/acceptance/Sx.md`, дифф этапа, вывод тестов и команд.

Пункты `[главный]`: без их проверки точка не имеет смысла (`03`, раздел 5).

1. [главный] Каждая проверка из раздела «Приёмка» файла этапа есть в отчёте. Пропущена: critical.
2. [главный] У каждой проверки PASS есть доказательство: вывод команды, файл, скриншот. Только пересказ: critical.
3. [главный] Вывод команды в отчёте действительно показывает то, что заявлено (например, «Совпало 50 из 50», а не 49): critical.
4. Каждый шаг из раздела «Шаги» файла этапа сделан или перенесён в `docs/backlog.md` с причиной. Молча пропущен: major.
5. Запрет из ТЗ реализован только в промте, без проверки кодом и теста: critical.
6. В диффе есть секрет, пароль, ключ, токен: critical.
7. В диффе есть работа другого этапа без записи в `docs/decisions.md`: major.
8. Отступление от архитектуры без записи в `docs/decisions.md`: major.
9. Раздел «Что проверить заказчику руками» выполним за 15-30 минут человеком без программирования: иначе major.
