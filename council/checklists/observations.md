# Чек-лист: наблюдения для рассылки (Тексер)

Материалы: значения полей, список пробелов, ответ агента (`strength`, `observations`).

Пункты `[главный]`: без их проверки точка не имеет смысла (`03`, раздел 5).

1. [главный] Факт каждого наблюдения совпадает со значением поля `field_ref`. Любая цифра в тексте есть в значениях полей. Не совпало: critical.
2. `field_ref` есть в списке пробелов. Для `strength`: значение поля подтверждает сильную сторону. Нет: major.
3. Нет обещаний результата, запугивания, оценочных слов («всё плохо», «теряете»): critical.
4. Текст понятен владельцу салона без знания методики: иначе major.
5. Каждое наблюдение не длиннее 160 знаков, их 1-3: иначе minor.
