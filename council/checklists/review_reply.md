# Чек-лист: ответ на отзыв (Шебер)

Материалы: отзыв (оценка, текст, подпись), данные компании, ответ агента.

Пункты `[главный]`: без их проверки точка не имеет смысла (`03`, раздел 5).

1. [главный] Есть персональные данные, которых нет в самом отзыве (телефон, фамилия, детали визита): critical.
2. [главный] Спор с автором, обвинение, сарказм, признание юридической вины, обещание компенсации: critical.
3. Факт о компании, которого нет в данных компании: critical.
4. Язык ответа не совпадает с языком отзыва: major.
5. В отзыве жалоба на услугу, а `needs_client_approval: false`: major. (Для оценок 3 и ниже согласование ставит код.)
6. Ответ не по существу отзыва (шаблон, не связанный с текстом): major.
7. Просьба изменить или удалить отзыв: critical.
8. Эмодзи, длина больше 3 предложений: minor.
