# Чек-лист: поля карточки, прочитанные моделью (Барлау)

Материалы: скриншот страницы, текст блоков, поля, которые записал агент.

Пункты `[главный]`: без их проверки точка не имеет смысла (`03`, раздел 5).

1. [главный] Каждое непустое поле видно на скриншоте или в тексте с тем же значением. Цифра не совпала: critical.
2. Поле `null` там, где значение на скриншоте видно явно: major (агент пропустил).
3. [главный] 0 стоит там, где площадка ноль не показывает (поле просто не видно): critical (это выдумка, должно быть null).
4. [главный] Значение взято не с этой площадки (например, рейтинг 2ГИС в поле Яндекса): critical.
5. Категории цен: `company_price`, `photo_only`, `empty` (2ГИС) и `yes`, `yes_outdated`, `no` (Яндекс) соответствуют видимому.
