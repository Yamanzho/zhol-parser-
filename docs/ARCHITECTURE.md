# Архитектура локального Жол

Панель, API и база работают на одном Mac. Наружу порты не публикуются.

## Процессы

| Часть | Где работает | Назначение |
|---|---|---|
| `web` | Docker, Vite | Панель React. Хост: `127.0.0.1`, порт `WEB_PORT` (15173). Внутри контейнера слушает 5173. |
| `api` | Docker, FastAPI | `uvicorn` на `0.0.0.0:8000` внутри контейнера. На хост публикуется только `127.0.0.1`, порт `API_PORT` (18080). |
| `worker`, `browser-worker`, `scheduler` | Docker | Очереди и расписание. Своих портов нет. |
| `db` | Docker, PostgreSQL 16 | Том `pgdata`. Порт базы на хост по умолчанию не открыт. |
| `backup` | профиль `backup` | Цикл резервных копий в `data/backups`. Каталог в Git не входит. |
| сборщик | LaunchAgent `kz.duna.zhol.collector` | Один процесс Selenium и Chrome на текущего пользователя macOS. |

Файл `docker-compose.offline.yml` добавляет локальный вход и каталоги фикстур. Профиль `collector` в обычном запуске выключен, чтобы не появился второй сборщик.

Запуск описывают три команды Finder: `Установить Zhol.command`, `Запустить Zhol.command`, `Остановить Zhol.command`.

## Конфигурация

`.env` создается из `.env.example` и остается на диске пользователя. Туда входят пароль PostgreSQL, токен панели, локальный вход и пустые разрешения площадок. `scripts/zhol_write_env.py` не заменяет уже существующий файл.

Города: `zhol/agents/scout/localities.py`. Категории: `config/categories.yaml`. Модели и цены в `config/models.yaml` остаются закрытыми, пока цены не заполнены отдельно.

## Данные сбора

Снимок карточки пишется в `card_snapshots`. Повторный сбор добавляет снимок, а не переписывает предыдущий. Выгрузка `zhol/agents/scout/platform_rows.py` читает последние снимки 2ГИС и Google и пишет книгу Excel. Яндекс в эту книгу не входит.

Миграции применяет Alembic при запуске. Пустая база нового пользователя не содержит компаний из чужой установки.

## Что сознательно не публикуется

`.env`, том PostgreSQL, `data/`, журналы, профиль Chrome, `source/etalon-50.csv`, `source/base-contacts.csv` и снимки экрана приемки. История Git этого выпуска начинается пустой: в ней нет этих файлов.
