# Установка Жол на macOS

Инструкция для второго компьютера. Существующая установка разработчика не переносится: у каждого пользователя своя база и свой `.env`.

## Программы

1. Установите Docker Desktop и дождитесь, пока он запустится.
2. Установите Python 3.12 или новее. На macOS команда `python3` иногда остается версией 3.9. Установщик ищет `python3.12`, затем `python3.13`, затем `python3`.
3. Установите Google Chrome. Сборщик открывает отдельный профиль в `~/Library/Application Support/Almaty2GISCollector/ChromeProfile` и не входит в личный профиль Chrome.

## Первый запуск

1. Скачайте или клонируйте репозиторий.
2. Дважды щелкните `Установить Zhol.command`.

Установщик проверяет Python, Docker и Chrome. Если файла `.env` нет, он создает его из `.env.example` и записывает случайные пароль базы, ключ файлов, ключ секретов, токен панели и локальный вход. Пользователь базы `zhol`, имя базы `zhol`. Если `.env` уже есть, файл не переписывается.

Затем установщик создает пустую PostgreSQL, только если контейнер базы этого проекта еще не существует. Существующий том не удаляется и не пересоздается.

Для текущего пользователя macOS ставится один сборщик: LaunchAgent `kz.duna.zhol.collector`. Профиль Docker `collector` не включается. Повторная установка в ту же папку не перезапускает уже работающий сборщик.

3. Дважды щелкните `Запустить Zhol.command`.

Скрипт поднимает базу, проверяет её схему, затем поднимает API, панель, очереди и резервное копирование и открывает панель. Новой пустой базе он сам создаёт таблицы. Базу с данными он не обновляет: если схема устарела, запуск останавливается и предлагает «Обновить базу Zhol.command». Порты по умолчанию: API `127.0.0.1:18080`, панель `127.0.0.1:15173`. Их можно сменить в `.env` ключами `API_PORT` и `WEB_PORT` до первого запуска.

4. `Остановить Zhol.command` останавливает контейнеры и оставляет том с данными.

## Разрешения площадок

В `.env` три пустых ключа:

- `ZHOL_2GIS_BROWSER_GRANT`
- `ZHOL_YANDEX_BROWSER_GRANT`
- `ZHOL_GOOGLE_BROWSER_GRANT`

Допустимы только тексты `written-browser-retention-local` и `written-browser-retention-commercial`. Пустая строка закрывает источник. Разрешение одной площадки не открывает другую. Эти строки не хранятся в Git и не копируются установщиком из примера.

Ключ Catalog API 2ГИС, если он есть, записывается в `DGIS_CATALOG_KEY`. Пустое значение оставляет этот способ сбора выключенным.

## Что не входит в репозиторий

Пароли, токены, выгрузки Excel, журналы, снимки базы, профиль Chrome и собранные карточки. Их создает уже работающая программа на компьютере пользователя.
