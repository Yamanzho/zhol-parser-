# Жол: короткий запуск

Панель и API открываются только на этом компьютере.

## Демонстрация без настройки

Готовое приложение: `dist/Zhol Demo.app`. Дважды щелкните его. Страница откроется в браузере сама. Python, Docker, PostgreSQL, ключи и Chrome на этом компьютере не нужны. Карты не открываются. Рабочая база не используется.

Если демонстрация уже запущена, второе открытие не поднимает второй сервер и пишет, что страница уже доступна. Если порт `8765` занят другой программой, приложение не закрывает её и показывает сообщение по-русски. Закрытие приложения из Dock останавливает учебный сервер.

Собрать приложение на Mac с процессором Apple (ARM64), где Жол уже установлен в `.venv`:

```bash
scripts/build-macos-demo.sh
```

Скрипт собирает панель, кладёт её в `demo/static` и упаковывает `dist/Zhol Demo.app`. npm и PyInstaller нужны только для этой сборки, не для запуска готового приложения.

Пока приложения нет, учебный режим можно открыть двойным щелчком `Запустить демо Zhol.command`. Тогда на компьютере нужен Python 3.12 из `.venv` или команда `python3`. Если Python не найден, окно напишет об этом и не начнёт притворяться, что демонстрация запущена.

Адрес вида `http://127.0.0.1:8765`. Описание учебных адресов: `http://127.0.0.1:8765/openapi.json`.

## Рабочий режим

1. Дважды щелкните `Установить Zhol.command`, если Жол ещё не установлен.
2. Дважды щелкните `Запустить Zhol.command`.
3. В панели три раздела: Сбор, Компании, Выгрузка. Прежние разделы лежат в «Дополнительно».

Рабочий сбор использует уже существующие сборщики и разрешения площадок. Если площадка закрыта, кнопка сбора не запускает браузер и пишет причину.

## Другая программа

Рабочий API: `http://127.0.0.1:18080`. Справка: `http://127.0.0.1:18080/docs`.

Нужен токен из `.env`, заголовок `Authorization: Bearer ...`. Запрос из браузера дополнительно передаёт `X-Zhol-Request: admin`. Повтор с тем же `idempotency_key` возвращает то же задание.

Примеры: `examples/python_client.py` и `examples/curl.sh`.

Команда без панели:

```bash
python -m zhol.cli jobs --api http://127.0.0.1:18080 --token "$ZHOL_ADMIN_TOKEN" create --platform 2gis --city Алматы --query "салон красоты" --limit 20
```

Учебный сервер:

```bash
python -m zhol.cli demo --open
```

## Ограничения

- Демонстрация не собирает живые карточки и не пишет в PostgreSQL.
- Яндекс Карты и Google Maps в рабочем режиме остаются закрытыми, пока для них нет отдельного разрешения. В демонстрации они только имитируются.
- Старая книга рассылки по-прежнему без листа Яндекса. Новая выгрузка задания включает те площадки, которые реально собраны.
- Одна выгрузка пишется по строкам и не загружает всю таблицу в память. CSV и JSON не ограничены 5000 строками. Книга Excel вмещает не больше 1 048 575 строк данных.
- Совпадение компании между площадками по-прежнему не сливает два одинаково подходящих кандидата и не считает общий телефон с другим адресом одной карточкой. Одно точное совпадение при наличии сомнительного кандидата тоже не сливается. Неоднозначный результат не превращается в подтверждённое совпадение.
- Ключи сопоставления обновляются при обычной записи через приложение. После прямой SQL-загрузки выполните `python -m zhol.cli rebuild-match-keys`. Команда не меняет компании. Установка и откат миграции: `docs/RELEASE_RU.md`.

## Приёмка демонстрации

| Требование | Итог |
|---|---|
| A. Другая программа управляет сбором и забирает результат по описанному API | PASSED |
| B. Человек без настройки открывает сбор, компании и выгрузку | PASSED |
| C. Готовое приложение стартует на Mac ARM64 без Python, Docker и базы | PASSED |

Проверка C выполнена запуском `dist/Zhol Demo.app` с пустым окружением (`env -i`, системный `PATH`, каталог `/tmp`). Отдельный компьютер с чистой установкой macOS не использовался. Рабочая база не открывалась. Живые запросы к картам не отправлялись.
