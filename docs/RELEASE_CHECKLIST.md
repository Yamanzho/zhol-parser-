# Приемка публичного выпуска

Выпуск можно отправлять в https://github.com/Yamanzho/zhol-parser-.git только если каждый пункт ниже выполнен на машине, с которой делается коммит. Отправка без отдельного согласия оператора не выполняется. Принудительная перезапись истории не используется.

## Секреты

- В истории Git нет коммитов с `.env`, паролями, токенами и таблицами контактов. Первая публикация идет из пустой истории.
- `.env` не входит в индекс. `.env.example` содержит пустые пароль, токен, вход и три разрешения площадок.
- `source/etalon-50.csv` и `source/base-contacts.csv` не входят в индекс.
- `data/`, журналы, выгрузки Excel, профиль Chrome и снимки приемки не входят в индекс.
- Разрешения работающей установки не копируются в пример и в plist.

## Чужой Mac

- `Установить Zhol.command` проверяет Python 3.12, Docker и Chrome.
- Новый `.env` получает свой пароль. Существующий файл не переписывается.
- Новая база создается только если контейнера базы еще нет.
- LaunchAgent один, `kz.duna.zhol.collector`. Профиль Docker `collector` выключен.
- API и панель опубликованы на `127.0.0.1`.

## Проверки до коммита

- `python3 -m pytest` проходит. Тесты не открывают живые карты.
- `npm run build` в `web/` проходит.
- `bash -n` проходит для скриптов и команд Finder.
- `docker compose config` показывает привязку к `127.0.0.1` и не включает сервис `collector`.
- Отдельный проект Compose поднимает пустую PostgreSQL 16, Alembic создает таблицы, `companies` пуста, том этого проекта удаляется. Рабочая база не используется.
- Выгрузка Excel покрыта тестами на синтетических строках.
- Поиск секретов по списку файлов к публикации ничего не находит.

## Документы

- README.md, docs/INSTALL_MAC_RU.md, docs/USER_GUIDE_RU.md, docs/ARCHITECTURE.md, docs/TROUBLESHOOTING_RU.md и этот список описывают фактический справочник городов, категории, пустые разрешения, паузу и остановку, PostgreSQL и два листа Excel.
- Документы не обещают, что живой сбор Яндекса всегда доступен.
