# Если Жол не запускается

## Окно установки сразу закрывается с ошибкой

- `python3 --version` должен показать 3.12 или новее.
- Docker Desktop должен быть установлен и уже запущен. Проверка: `docker info`.
- Нужна команда `docker compose`, которая входит в Docker Desktop.
- Google Chrome должен лежать в `/Applications/Google Chrome.app`.

Повторный щелчок по `Установить Zhol.command` не стирает `.env` и не пересоздает уже созданную базу.

## «Файла .env нет»

Сначала запустите `Установить Zhol.command`. `Запустить Zhol.command` сам пароль не придумывает и пустой `.env` не создает.

## Панель не открывается

Смотрите `~/Library/Logs/Zhol/startup.log`. Порты по умолчанию 18080 и 15173 слушают только `127.0.0.1`. Адрес `localhost` подходит, адрес другого компьютера в сети не подходит.

Если порт занят, остановите Жол, поменяйте `API_PORT` или `WEB_PORT` в `.env` и запустите снова. Том базы при этом остается.

## Сбор Яндекса прерывается

Это ожидаемо, если страница отвечает ограничением доступа. Текст страницы `limited`, «доступ ограничен», «доступ запрещ» или `access denied` останавливает задание. HTTP 429 может быть причиной и при этом не попасть в журнал отдельным кодом. Повторять такой обход или менять профиль, чтобы обойти ограничение, не нужно. 2ГИС и Google от этого сообщения не чинятся: у них свои разрешения и свои страницы.

Для городов кроме Алматы Яндекс в справочнике выключен. Это не ошибка установки.

## Сборщик Chrome

Один агент: `kz.duna.zhol.collector`. Журналы: `~/Library/Logs/Zhol/collector.log` и `collector.err.log`. Состояние: `scripts/zhol-collector-macos.sh status`.

Если Docker-профиль `collector` когда-нибудь окажется запущен, `Запустить Zhol.command` откажется продолжать. Рабочий сборщик на Mac уже один, второй в контейнере не нужен.

Код из SMS и обход проверки площадки программа не запрашивает. Если кабинет просит код, это отдельная ручная задача, не часть установки.

## База

Контейнеры можно остановить. Данные остаются в томе Docker проекта. Команда установки не выполняет `docker compose down -v` для уже существующей базы.

Тесты установки используют отдельное имя проекта Compose и свой пароль. Рабочую базу разработчика они не открывают.
