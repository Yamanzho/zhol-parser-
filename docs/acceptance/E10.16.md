## Что остаётся

В списке и в шапке компании адрес остаётся «Нет данных», если адрес есть только в снимке Яндекса или Google. Шапка прямо пишет: «Проверенного адреса 2ГИС нет». Сам адрес и ссылка при этом есть на вкладке площадки.

Форма «Сбор компаний» не даёт выбрать Яндекс и Google. Такой сбор запускается через API сохранённых страниц. Живой обход по-прежнему выключен.

Если у каталога сохранённых страниц нет файла `pages/blank.png`, задание падает уже после записи компаний. С файлом на месте те же задания проходят.
