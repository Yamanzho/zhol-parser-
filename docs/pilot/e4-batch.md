# E4: пакетный сбор и Excel

Дата: 11.10.2026. Режим по умолчанию читает сохранённые страницы. Это не живой сбор и не рассылка.

## Команда

Десять сохранённых салонов Алматы, все три площадки, файл только из этого пакета:

```bash
python -m zhol.cli scout-batch \
  --city "Алматы" \
  --category "Салон красоты" \
  --platforms 2gis,yandex,google \
  --limit 10 \
  --source-mode fixture \
  --out data/export/batch-almaty.xlsx
```

Без `--limit` берутся все компании каталога с этим городом и категорией. Число 100 в примере не зашито в программу.

Продолжить прерванный пакет, не собирая заново уже записанные компании:

```bash
python -m zhol.cli scout-batch --resume <id> --source-mode fixture
```

Номер печатается в строке `batch <id>`. Готовые компании не создают второй снимок с тем же ключом сбора. Сбойная или заблокированная строка сама не повторяется. Строка, оборванная в середине, повторяется ещё один раз. После второго обрыва она остаётся `failed`.

Живой поиск по городу и категории:

```bash
ZHOL_SCOUT_LIVE=1 python -m zhol.cli scout-batch \
  --city "Алматы" \
  --category "Салон красоты" \
  --source-mode live
```

Команда останавливается и ничего не открывает. См. ограничения ниже.

## Что умеет каждая площадка

Каталог сохранённых страниц: `tests/fixtures/catalog.yaml`. В нём 10 салонов Алматы, 2 ресторана Астаны и 1 парикмахерская Алматы. Город сравнивается без учёта регистра. Категория должна быть точной меткой из `config/categories.yaml`. Слово «салон» отклоняется: оно неоднозначно.

| Площадка | Поиск по городу и категории | Чтение сохранённой страницы | Живое чтение |
|---|---|---|---|
| 2ГИС | не реализован | карточка по `id_2gis` | только уже известный адрес карточки, отдельной командой `scout`, не этим пакетом |
| Яндекс | не реализован | поиск и карточка, если файл сохранён | нет каталога; карточка известной компании читалась в E3 |
| Google | не реализован | поиск, если файл сохранён | в E3 публичный поиск не показал салоны Badi и Velara |

Нет файла страницы: площадка `not_found`, ячейки пустые, контакт не придумывается. Площадка не выбрана в `--platforms`: `not_checked`, не `not_found`. Проверка робота или отказ доступа: `blocked`, поля этой страницы в Excel не попадают, остальные выбранные площадки продолжаются. Совпадение `ambiguous` или другой адрес не сливается с компанией и не заполняет общие контакты.

Общие колонки Phone, WhatsApp, Instagram, Website, Email берутся только из подтверждённого совпадения `found` без пометки проверки человеком. Порядок источников: `config/contacts.yaml`. Пустое значение не стирает уже записанное. Явный 0 в числе отзывов или фото остаётся 0.

## Excel

40 колонок, одна строка на филиал. Файл пишется во временный `*.partial` и заменяется целиком. Прерванный пакет оставляет предыдущий файл и строки уже завершённых компаний. Балл берётся из сохранённого аудита. У компаний из каталога аудита нет, поэтому балл пустой. Непроверенное совпадение баллом не становится.

Знаки `=`, `+`, `-`, `@` в начале ячейки записываются как текст.

## Свежесть и проверка совпадения

Снимок хранит адрес страницы, время и файл. Старый снимок не удаляется. Новый пакет создаёт новые снимки, а повтор того же пакета их не дублирует. Совпадение имени и адреса без конфликта улицы и дома записывается. Общий телефон при другой улице и доме остаётся неоднозначным. Одинаковый телефон сам по себе филиалы не сливает.

Эталонные 50 компаний этой командой не перезаписываются: каталог использует другие id.

## Ограничения доступа

Живой обход каталога 2ГИС, Яндекса и Google не подключён. Программа не обходит проверку робота, не меняет IP и не запускает рассылку. Лимит площадки не считается разрешением собирать сверх того, что страница сама показала.
