# E4.1: поиск по сохранённым страницам

Дата: 11.10.2026. Режим по умолчанию читает файлы на диске. Это не живой обход и не рассылка.

## Команда

Сохранённые страницы поиска, затем те же карточки и тот же Excel, что в E4:

```bash
python -m zhol.cli scout-batch \
  --city "Алматы" \
  --category "Салон красоты" \
  --platforms 2gis,yandex,google \
  --source-mode fixture \
  --discovery tests/fixtures/discovery/almaty-salon \
  --fixtures tests/fixtures/discovery/almaty-salon/pages \
  --out data/export/discovery-almaty.xlsx
```

Ручной экспорт, который человек сам сохранил из браузера, лежит в каталоге с `manifest.yaml`:

```bash
python -m zhol.cli scout-batch \
  --city "Алматы" \
  --category "Салон красоты" \
  --source-mode manual \
  --discovery path/to/manual-pages
```

Пауза и остановка проверяются между страницами поиска. Продолжение читает курсор пакета и не создаёт второй снимок для уже собранной строки:

```bash
python -m zhol.cli scout-batch --resume <id> --source-mode fixture
```

Живой поиск по городу и категории по-прежнему останавливается и ничего не открывает. Для 2ГИС обход каталога закрыт в коде.

## Что читается

Первая страница каждой площадки указана в `manifest.yaml`. Дальше программа идёт по локальной ссылке следующей страницы и по локальному фрагменту прокрутки. Ссылка на сайт не открывается. Адрес фирмы берётся только если он есть на странице и подходит к правилам этой площадки. Нет файла: площадка пропускается, компания не придумывается. Проверка робота или отказ: сбор этой площадки останавливается, фирмы с этой страницы не записываются.

Название, адрес и категория приводятся к одному виду. Незнакомая или неоднозначная рубрика остаётся пустой и не попадает в пакет. Телефон, WhatsApp, Instagram, сайт и почта записываются только когда значение на странице им соответствует. Чужой номер при том же имени и другом доме не сливает филиалы.

Скриншот страницы и время, показанное на ней, лежат рядом с находкой. Если страница не показала время, ставится время чтения.

## Excel

Тот же файл на 40 колонок. Готовая строка пишется до следующей компании. Прерванный пакет оставляет уже завершённые строки. Эталонные 50 компаний этим поиском не перезаписываются.
