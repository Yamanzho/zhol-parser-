# E7.5: планы правок из аудита Бека

Дата: 11.10.2026. Команды читают книгу аудита и собирают план. Карточки не открываются, форма не отправляется, правка не считается сделанной.

E7.5.1 проверяет настоящую книгу `source/bek-audit-original.xlsx` (листы «Сводка», «Контакты для связи», «Все данные», «Как читать»). Книга из `etalon-50.csv` остаётся только регрессией старого формата.

E7.5.2 читает второй раздел той же книги: 100 строк «косметология (Almaty)». Балл копируется из листа. Рейтинг Яндекса, который на 0,1 ниже 2ГИС, и короткий id Яндекса не записываются. «Не найдена» в Google остаётся проверкой, а не подтверждённым отсутствием.

```bash
python -m zhol.cli import-bek-audit --file karty-salony-almaty-2026-10.xlsx
python -m zhol.cli bek-audit-plan --company-id <id>
```

Повторный импорт ничего не добавляет. Снимок со статусом `verified` и более поздней датой не перезаписывается. Балл берётся из колонок книги, `score()` не меняется.

Задача `ready_for_preparation` появляется только если команда `prepare-2gis-listing`, `prepare-yandex-listing` или `prepare-google-listing` умеет записать поле и уже есть утверждённый факт, доступ `verified` и известный контрол кабинета. Отсутствующая карточка остаётся `unsupported`: эти команды карточку не создают. Ответы на отзывы, подтверждение владельца, реальные фото, сверка площадок и недостающие факты клиента остаются ручной работой.
