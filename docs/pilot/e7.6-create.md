# E7.6: подготовка новой карточки

Дата: 12.10.2026. Команда заполняет пустую форму создания и останавливается перед «Создать». Карточка на площадке не появляется. Команды правки существующей организации по-прежнему карточку не создают.

## Команды

```bash
python -m zhol.cli prepare-2gis-create --order-id <id> --page tests/fixtures/cabinet/2gis-create.html --evidence data/listing/<id>
python -m zhol.cli prepare-yandex-create --order-id <id> --page tests/fixtures/cabinet/yandex-create.html --evidence data/listing/<id>
python -m zhol.cli prepare-google-create --order-id <id> --page tests/fixtures/cabinet/google-create.html --evidence data/listing/<id>
```

`--page` это сохранённый HTML формы создания. Живой адрес `https://...` открывается только при `ZHOL_2GIS_CABINET=1`, `ZHOL_YANDEX_CABINET=1` или `ZHOL_GOOGLE_CABINET=1`. Пароль, код и проверка «не робот» программа не вводит.

## Когда черновик разрешён

Нет сохранённого id и ссылки на карточку. Свежий проверенный поиск за 14 дней говорит `not_found`. Старый аудит и строка «не найдена» из книги Бека этим поиском не считаются. На заказе есть отдельное подтверждение человека, что карточки нет. Доступ владельца `verified`. Открытая страница это форма создания этой площадки, без id карточки и без чужого названия.

Иначе статус `existing_listing`, `uncertain` или `ownership_required`, и открывается задача человеку. Дубль не готовится.

## Что попадает в черновик

Только утверждённые факты, у которых есть источник: название, адрес, рубрика, телефон, и где форма это показывает, сайт, часы, услуги, описание. 2ГИС описание не пишет. Google не пишет услуги, WhatsApp и Instagram. Картинки в этом шаге не загружаются. Нет факта: поле остаётся пустым, значение не придумывается.

Повтор с тем же итогом не добавляет вторую строку журнала. Скриншоты до и подготовленного состояния и `review.json` лежат в каталоге доказательств. Задачи `2gis_create_review`, `yandex_create_review` и `google_create_review` это разрешение на следующий этап, не на отправку из этой команды.
