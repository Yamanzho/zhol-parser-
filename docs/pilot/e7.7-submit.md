# E7.7: отправка утверждённого черновика

Дата: 12.10.2026. Команда может отправить уже подготовленный черновик только после отдельного одобрения человека и только в режиме offline. Живой кабинет не открывается. Нажатие «Сохранить» или «Создать» не означает, что карточка опубликована.

## Команды

```bash
python -m zhol.cli approve-listing --order-id <id> --platform yandex --operation create --page tests/fixtures/cabinet/yandex-create.html --evidence data/listing/<id>
python -m zhol.cli submit-listing --order-id <id> --platform yandex --operation create --page tests/fixtures/cabinet/yandex-create.html --evidence data/listing/<id>
python -m zhol.cli verify-listing --order-id <id> --platform yandex --operation create --page tests/fixtures/cabinet/yandex-create.html --evidence data/listing/<id>
```

`--mode` принимает только `offline`. Адрес `https://...` не открывается. Пароль, код из СМС и сессия в доказательства не пишутся.

## Одобрение

Одобрение привязано к заказу, площадке, операции (`create` или `update`) и версии пакета правок. В нём зафиксированы точные значения полей и файлы доказательств подготовки. Если значение в пакете изменилось, одобрение гасится. Перед нажатием заново проверяются доступ владельца и организация на странице. Вход и проверка владения остаются действием человека.

## Что записывается

Попытка и итог лежат в `listing_submissions` и `listing_submission_attempts`. Повтор после `submitted`, `moderation_pending`, `published`, `rejected` или `uncertain` кнопку не нажимает. Неясный Create сам не повторяется. Скриншот до, пакет, время, ответ площадки, скриншот после и статус модерации пишутся в `submission.json`.

Кнопка по площадкам: 2ГИС и Яндекс «Создать» / «Сохранить», Google «Create» / «Сохранить». «Опубликовать» не нажимается. Статус `published` ставит только отдельная проверка страницы, не сам клик.
