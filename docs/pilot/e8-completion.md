# E8: проверка выполнения и отчет клиенту

Дата: 12.10.2026. Команды читают уже сохраненные заказ, пакет правок, отправку и снимки. Кабинет не открывается. Нажатие «Сохранить» или «Создать» не считается публикацией. Сухой прогон и подготовленный черновик не называются выполненной работой.

## Команды

```bash
python -m zhol.cli verify-order --order-id <id>
python -m zhol.cli generate-completion-report --order-id <id> --out data/reports/<id>
```

`verify-order` печатает состояние каждой площадки заказа. `generate-completion-report` пишет `completion.json` и `completion.html` и одну строку `reports` с `period=setup`. PDF не создается. Повтор с теми же данными не добавляет вторую строку и не меняет файлы.

## Когда правка считается проверенной

Статус `published_verified` ставится только если после `submitted_at` есть снимок `card_snapshots` с `purpose=report`, статус снимка `verified`, файл скриншота на месте, и у каждого утвержденного поля есть источник (`url`, `seen_at`) и то же значение. Это сохраненное доказательство. `live_verified` остается `false`.

Иначе площадка остается `not_submitted`, `submitted`, `moderation_pending`, `rejected`, `uncertain` или `human_required`. Снимок старше 14 дней, отсутствующий скриншот, флаг live на снимке, другая версия пакета или сменившееся утверждение текста не дают `published_verified`. Часть площадок может совпасть, пока остальные нет.

Иллюстрация в отчете подписана «Иллюстрация, не фотография компании.» Пароли, токены и шифр доступа в отчет не попадают.
