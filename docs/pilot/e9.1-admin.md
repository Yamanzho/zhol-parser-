# E9.1: локальная панель администратора

Дата: 12.10.2026. Панель только читает уже сохраненные записи. Она не открывает кабинет, не отправляет карточку, не вызывает Bek и не запускает живой сбор города.

Действия фикстур, ручных страниц и офлайн-прогонов описаны в `docs/pilot/e9.2-admin.md`. Живой кабинет по-прежнему закрыт.

Пока `ZHOL_ADMIN_TOKEN` пустой, маршруты `/api/v1/admin` отвечают 503. `/health` остается открытым. Токен задается в окружении и вводится в форме. В ответах нет паролей, токенов и шифра доступов.

Порты опубликованы только на `127.0.0.1`. Если 18080 или 15173 заняты: `API_PORT` и `WEB_PORT`.

## Обычный запуск

Рабочий `config/models.yaml` по-прежнему не стартует без цен R6 и ключей моделей.

```bash
export ZHOL_ADMIN_TOKEN="$(openssl rand -hex 32)"
docker compose up --build db api web
```

Панель: http://127.0.0.1:15173
API: http://127.0.0.1:18080/health

## Офлайн-режим

Отдельный файл подставляет тестовый каталог моделей. Ключи в файле не записаны: для старта их нужно положить в окружение, панель ими не пользуется. Живые вызовы моделей этот режим не включает.

```bash
export ANTHROPIC_API_KEY=offline
export OPENAI_API_KEY=offline
export GOOGLE_API_KEY=offline
export ZHOL_ADMIN_TOKEN="$(openssl rand -hex 32)"
docker compose -f docker-compose.yml -f docker-compose.offline.yml up --build db api web
```

Без Docker, из корня репозитория:

```bash
export DATABASE_URL=postgresql+psycopg://zhol:zhol@127.0.0.1:5432/zhol
export ZHOL_CONFIG_DIR=tests/golden/review-engine/config
export ANTHROPIC_API_KEY=offline OPENAI_API_KEY=offline GOOGLE_API_KEY=offline
export ZHOL_ADMIN_TOKEN="$(openssl rand -hex 32)"
uvicorn zhol.api.main:app --host 127.0.0.1 --port 18080
```

```bash
cd web && npm ci && npm run dev
```

Vite слушает `127.0.0.1:5173` и, если порт занят, берет следующий.
