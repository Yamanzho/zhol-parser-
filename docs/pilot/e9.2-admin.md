# E9.2: действия локальной панели

Дата: 13.10.2026. Панель по-прежнему слушает только localhost и требует `ZHOL_ADMIN_TOKEN`. Запись возможна только с заголовком `X-Zhol-Request: admin`. Токен лежит в памяти вкладки и не является cookie.

Панель запускает фикстурный или ручной сбор, импортирует уже готовый XLSX аудита, создает локальный заказ, готовит черновики офлайн, считает сухой план правок, подтверждает одну версию и один пакет, имитирует офлайн-отправку и пишет отчет JSON/HTML. Она не открывает живой кабинет, не вызывает Bek и не ходит в платный API модели.

Долгий сбор это задача `admin.scout_batch` в существующей очереди PostgreSQL. С E9.3 ее забирает процесс `worker` на очереди `main`, а не процесс API. Ответ HTTP содержит id задачи и не ждет окончания пачки. Повторный клик с теми же параметрами возвращает ту же задачу, пока она не завершена.

Файлы панели лежат в `data/admin` (в контейнере это `/app/data/admin`). Каталог или папка сохраненных страниц должны лежать в `data/admin/sources` или, при локальной разработке, в `tests/fixtures`. Имя вроде `catalog.yaml` допустимо. Адрес страницы и путь с `..` отклоняются. Скачивание отдает только файл внутри `data/admin`.

## Обычный запуск

Рабочий `config/models.yaml` по-прежнему не стартует без цен R6 и ключей моделей.

```bash
export ZHOL_ADMIN_TOKEN="$(openssl rand -hex 32)"
docker compose up --build db api web
```

Панель: http://127.0.0.1:15173
API: http://127.0.0.1:18080/health

## Офлайн-режим

Ключи в файле не записаны. Этот режим не включает живые вызовы моделей. Оверлей монтирует `tests/fixtures`, поэтому в форме сбора можно указать `catalog.yaml`.

```bash
export ANTHROPIC_API_KEY=offline
export OPENAI_API_KEY=offline
export GOOGLE_API_KEY=offline
export ZHOL_ADMIN_TOKEN="$(openssl rand -hex 32)"
docker compose -f docker-compose.yml -f docker-compose.offline.yml up --build db api web
```

Без Docker, из корня репозитория:

```bash
export DATABASE_URL=postgresql+psycopg://zhol:zhol@127.0.0.1:5432/zhol
export ZHOL_CONFIG_DIR=tests/golden/review-engine/config
export ANTHROPIC_API_KEY=offline OPENAI_API_KEY=offline GOOGLE_API_KEY=offline
export ZHOL_ADMIN_TOKEN="$(openssl rand -hex 32)"
uvicorn zhol.api.main:app --host 127.0.0.1 --port 18080
```

```bash
cd web && npm ci && npm run dev
```

Vite слушает `127.0.0.1:5173` и проксирует `/api` на API.
