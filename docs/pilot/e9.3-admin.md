# E9.3: сквозной офлайн-прогон

Дата: 13.10.2026. Панель по-прежнему слушает только localhost и требует `ZHOL_ADMIN_TOKEN`. Запись требует заголовок `X-Zhol-Request: admin`.

Сбор фикстур и ручных страниц ставится в очередь `main` как `admin.scout_batch`. Его выполняет уже существующий worker. API только возвращает id задачи. Пауза, остановка и продолжение записаны в строке пачки. Если worker остановился и срок аренды задачи истек, следующая попытка продолжает ту же пачку.

На странице правок у каждой площадки свои подготовка, подтверждение и офлайн-имитация. Подтверждение одной площадки не подтверждает другую. Имитация пишет `published: false`. Отчет пишет `live_verified: false`.

Живой кабинет, Bek и платные модели не включаются.

## Запуск

Нужны база, API, worker очереди `main` и панель. Без worker пачка останется в статусе `queued`.

```bash
export ZHOL_ADMIN_TOKEN="$(openssl rand -hex 32)"
docker compose up --build db api worker web
```

Панель: http://127.0.0.1:15173
API: http://127.0.0.1:18080/health

Офлайн-режим, без цен R6 в рабочем `config/models.yaml`:

```bash
export ANTHROPIC_API_KEY=offline
export OPENAI_API_KEY=offline
export GOOGLE_API_KEY=offline
export ZHOL_ADMIN_TOKEN="$(openssl rand -hex 32)"
docker compose -f docker-compose.yml -f docker-compose.offline.yml up --build db api worker web
```

Без Docker:

```bash
export DATABASE_URL=postgresql+psycopg://zhol:zhol@127.0.0.1:5432/zhol
export ZHOL_CONFIG_DIR=tests/golden/review-engine/config
export ANTHROPIC_API_KEY=offline OPENAI_API_KEY=offline GOOGLE_API_KEY=offline
export ZHOL_ADMIN_TOKEN="$(openssl rand -hex 32)"
uvicorn zhol.api.main:app --host 127.0.0.1 --port 18080
```

```bash
python -m zhol.worker --queue main
```

```bash
cd web && npm ci && npm run dev
```
