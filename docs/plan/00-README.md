# План реализации сервиса «Жол»

Версия 2 от 08.10.2026. Для Ербола и ИИ, с которым он работает. Заказчик: Тимур (Duna.kz).

Что строим, описано в ТЗ (`AGENTS.md` в корне репозитория, в пакете `source/AGENTS.md`). Этот пакет отвечает, как строить, кто что проверяет и как сдавать.

## Два вида промтов

1. **Промт для ИИ-разработчика** в каждом `stages/Sx.md`: Ербол вставляет его в Claude Code или Codex, чтобы ИИ написал код этапа.
2. **Рабочий промт агента** в `prompts/`: его сервис отправляет модели во время работы. У каждого JSON-схема ответа и версия.

## Общие правила

- Всё, что можно сделать кодом, делается кодом. Модель только для текста и решений по смыслу.
- У каждой задачи агента есть проверяющий (`03`). Непроверенное дальше не идёт.
- Запреты ТЗ проверяет код до вызова модели и после ответа; на каждый запрет тест.
- Ответ модели только JSON по схеме.
- Внешнее действие (правка, публикация, счёт) с ключом идемпотентности и записью в журнал.
- Секреты только в `.env` и хранилище. Не в git, логах, промтах, отчётах.
- Тексты клиенту без длинного тире (U+2013, U+2014). Деньги в тенге (₸).
- Время только через `timeutil.now()`; всё, что зависит от времени, проверяется с `--now`.
