# S6. Өнер: контент

**Зависит от:** S4. Можно вести параллельно с S5.

## Цель

Делать недостающие картинки для карточек и простое видео из материалов клиента. Никогда не генерировать работы мастеров, интерьер, людей.

## Входы

- ТЗ раздел 5.5; `03` раздел 3.1, строка 10; `04` раздел 2 (`brand`)
- Промт `prompts/creator-brief.md`; чек-листы `content_image`, `content_text`
- Требования площадок к картинкам и видео (размеры, форматы, вес): из официальной справки каждой площадки на дату работы,
  в `config/platforms.yaml`, раздел `media`, со ссылкой и датой
- Решение Р5 (`00-README.md`): какой генератор фонов подключать. До решения фоны только из фото клиента, сплошной цвет или градиент

## Скиллы

`zhol-stage`, `zhol-prompt`, `zhol-council` (точка `content`, две проверки), `verification-before-completion`, `/code-review`, `zhol-acceptance`.

## Шаги

1. Типы: `cover`, `promo_banner`, `price_image`, `video`.
2. `creator.make`: промт `creator-brief` → макет. Код проверяет: каждый текст макета с `source_ref` на профиль; цены совпадают с профилем;
   `generated_abstract` только если провайдер подключён.
3. Сборка картинок: HTML-шаблоны `cover_v1`, `promo_v1`, `price_v1` (логотип, цвета из `brand` или с логотипа, текст) → PNG через Playwright под размер площадки.
4. Видео `video_slides_v1`: `ffmpeg`, нарезка и склейка из `video_real` и `photo_real` клиента, титры из профиля, формат из `media`.
5. Точка `content`: Gemini по чек-листу `content_image`, GPT по `content_text` (текст с картинки распознаёт модель с картинками). Обе `pass`.
   Размер и вес файла проверяет код. Первые 10 работ дополнительно Тимуру в админке.
6. Когда весь контент пакета готов и проверен: `review.run(point=package)` для пакета с контентом.

## Промт для ИИ-разработчика

```text
Этап S6 сервиса «Жол». Прочитай AGENTS.md (5.5), docs/plan/03-proverka-i-konsilium.md (3.1 строка 10), 04-slovar-dannyh.md (2),
docs/plan/stages/S6.md, prompts/creator-brief.md, council/checklists/content_image.md и content_text.md.
Используй zhol-stage, zhol-prompt, zhol-council.

Задача: обложка, баннер акции, прайс картинкой (HTML-шаблон → PNG через Playwright) и простое видео из файлов клиента (ffmpeg).

Жёсткие правила:
- Текст и цены на картинке только из профиля клиента, код сверяет.
- Генерация только для фона и только если подключён провайдер. Люди, интерьер, работы, клиенты: запрещено (N12).
- Размеры и форматы из config/platforms.yaml media, взятые из официальной справки площадок со ссылкой и датой. Не придумывать.
- Видео только из video_real и photo_real клиента.

Золотой набор tests/golden/content/: 10 верных работ и 5 с ошибками (чужая цена, обрезанный текст, сгенерированный человек,
«лучший салон», неверный телефон). Покажи 2 обложки, 2 баннера, 1 прайс, 1 видео по материалам AOE.
В конце zhol-acceptance S6 и council-dev --stage S6.
```

## Приёмка

| # | Проверка | Ожидаемо |
|---|---|---|
| 1 | 6 работ по AOE | Тимур принимает не меньше 5 из 6 без правок текста и цен; замечания по оформлению исправлены |
| 2 | Задача «сделай фото работ мастера» | Отказ кодом, `human_task` |
| 3 | `eval --point content` | 10 из 10 верных проходят, 5 из 5 ошибок пойманы |
| 4 | Размеры | Совпадают с `media`; у каждого требования ссылка на справку и дата |

**Тимуру проверить руками (15 минут):** 6 работ из п. 1.
